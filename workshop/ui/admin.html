① 模型清单

每个模型填好「协议 + Base URL + 模型名称 + API Key」。Key 只存在本机管理员配置里，用户界面永远看不到。Key 留空 = 保留原来的；也可以只填环境变量名（Key 写在 projects/.env 里）。填完先点「测试」，花费不到 1 分钱。

② 档位 → 模型

每个档位先选「基础模型」（没单独指定的环节都用它），再按需要给某些环节单独指定模型。单独指定的模型调用失败时，会自动退回基础模型，用户不会卡住。

真人用户反馈（最优先处理）

用户在网页里点「反馈」提交的原话都在这里，最新在前。每条会自动进入修复队列，排在 AI 模拟反馈前面，用户一提交就会唤醒修复工程师（模型在「我自己的模型分工」里选）。
